# BOM 管理系統

安德斯醫學科技 — 料號庫存、BOM 建立與缺料試算的單檔網頁系統。

**線上使用**：https://kalvin7775-spec.github.io/bom-system/

## 功能

- **料號主檔** — 庫存、單價、安全庫存查詢與排序；單筆／批次／Excel 三種新增方式；用途反查（料號被哪幾張 BOM 使用）。
- **BOM 管理** — 多階層樹狀展開，階層以 1 / 1.1 / 1.1.1 編號；網頁內建 BOM 編輯器，可從料號主檔挑選品號加入、當場建檔、刪減主檔品號（仍被引用者阻擋刪除）。
- **需求試算** — 輸入生產數量展開總需求，比對庫存標示缺料，輸出缺料清單與採購金額。
- **更新比對** — 上傳新版料號總表，逐筆列出新增／消失／庫存增減／單價變動／欄位異動，確認後才套用並留存異動紀錄。
- **資料庫** — 料號主檔／BOM主檔／BOM明細三張表的 Excel，可離線維護後整份上傳。

## 技術

單一 HTML 檔，無後端。資料存於瀏覽器 IndexedDB，Excel 讀寫使用 SheetJS（CDN）。
資料轉移用資料庫 Excel 或 JSON 備份。

## 成本計算規則

預設「外購件不再展開」：料號主檔已有單位成本的組件視為整組外購，成本與需求以該品號本身計算，不再拆子件，避免與子件重複計價。可於「資料管理」頁關閉。
